# C Practice Page

태블릿 + 휴대용 키보드만으로 C언어를 공부하기 위한 정적 학습 페이지입니다.

## 현재 구현

- 17개 장 전체 목차(업로드된 750쪽 PDF의 장 구성 기준)
- 장별 핵심 개념 요약과 예제 코드
- 브라우저 안에서 C 코드 실행
- 34개 연습문제 자동 채점
- 연습문제는 정답 문자열이 아니라 실제 C 실행 결과를 테스트 케이스와 비교
- 작성 중 코드 자동 저장
- 장별 완료 / 문제 해결 진도 저장
- 모바일·태블릿 반응형 UI
- PWA 기본 캐시 지원

## C 실행 방식

[PicoC](https://github.com/KritR/picoc-js)의 WebAssembly 빌드를 Web Worker에서 실행합니다.
연습문제는 사용자가 제시된 함수 또는 매크로를 완성하면 테스트용 `main()`을 자동으로 붙여 실행합니다.
따라서 별도의 Visual Studio, VS Code, GCC 설치가 필요하지 않습니다.

> PicoC는 ISO C의 완전한 구현이 아닌 학습용 소형 인터프리터입니다.
> 파일 시스템, 일부 최신 C 기능 등은 데스크톱 컴파일러와 차이가 있을 수 있습니다.

## 실행

정적 파일이므로 웹 서버에서 `index.html`을 제공하면 됩니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요.

GitHub Pages에도 그대로 배포할 수 있습니다.

## 교재 사용 원칙

이 저장소는 사용자가 제공한 **쉽게 풀어쓴 C언어 Express 개정 4판**의 장 구성과 학습 주제를 기준으로 만든 개인 학습용 동반 페이지입니다.
교재 본문/그림/연습문제를 그대로 복제하지 않고, 장별 핵심 주제에 맞춘 요약과 별도 실습문제를 제공합니다.
